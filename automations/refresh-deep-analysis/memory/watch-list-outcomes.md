# Watch-List Outcomes

Ledger of every `watchList` item from prior `DEEP_ANALYSIS` runs. **Every item carries a probability** (`p ∈ [0,1]`, rounded to 0.05). Scored once the `window` has elapsed with a Brier score.

**Outcomes:** `hit` (1.0) / `miss` (0.0) / `partial` (0.5) / `n/a-no-resolution` (no Brier — drop from calibration).

**Brier per item:** `(p − outcome)²` where outcome ∈ {0, 0.5, 1}. Lower = better-calibrated.

**Workflow:**
- At start of run: score any unresolved items whose `window` has elapsed. Compute Brier per resolved item, then update `calibration.md`.
- At end of run: append the new run's `watchList` items as unresolved with their probabilities.
- Decay: rows older than 26 weeks → archive (move to bottom under `## Archived`).

## Hygiene rules

1. **Every active item has a probability.** No "unrated" entries.
2. **Probabilities rounded to 0.05.** False precision (0.673) is noise.
3. **0.50 is a refusal** — split into sharper sub-questions or commit to a direction.
4. **Outcome assignment requires a primary-source citation** in the lesson cell. Don't score from press summaries alone.
5. **Partial outcomes are real.** A markup that clears with some bad amendments isn't a clean hit — score as 0.5 partial.
6. **After scoring, update `calibration.md`.** Resolution without calibration update = run is incomplete.
