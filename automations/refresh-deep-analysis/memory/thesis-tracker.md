# Thesis Tracker

**Active primary theses + their falsification conditions.** Auto-flags theses for retirement when conditions are met or when stalled without new evidence for 4+ weeks.

Anti-confirmation-bias scaffolding: the analyst can't quietly drop a thesis when it stops working — it has to be explicitly retired with a reason.

## Hygiene rules

1. **Every `DEEP_ANALYSIS.primaryAnalysis` is logged here.** No primary thesis bypasses the tracker.
2. **Falsification conditions must be concrete and observable.** "Macro environment turns" is not a condition. "Fed delivers a hawkish hold with the dot plot showing zero cuts in 2026" is.
3. **Probability is updated every run.** Even if it doesn't move, write the same number with a 1-line "no new evidence" note. A stalled probability is itself a signal.
4. **Stalled-run counter increments when no new material evidence affects the thesis.** At 4 runs, auto-flag for retirement consideration in the next run's report.
5. **Retirement requires a stated trigger.** Not "this didn't pan out" — name the specific falsification condition that fired.
6. **Theses don't compete.** Multiple active theses are fine; they live in separate slots and don't need to share airtime in any single run.
7. **A falsifier is a wrongness test, not a noise test (SEP 13).** Cascade/volatility conditions are written downside-only or round-trip-conditioned, so that a move which confirms the read cannot retire the thesis on a technicality.
