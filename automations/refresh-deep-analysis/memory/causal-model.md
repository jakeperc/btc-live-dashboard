## Hygiene rules

1. **Edges are directional.**
2. **Strength downgrades with contradicting evidence.** A `strong` edge that fails once becomes `medium`; two failures retire it. (OCT 16: the long-end edge took its first failure at `medium` → `weak/medium`.)
3. **Mechanism > correlation.**
4. **Bias toward fewer, sharper edges.** 15–25 well-validated edges is a model.
5. **Cite evidence with run dates or external citations.**
6. **Condense, don't delete (SEP 13).** When an edge's evidence block exceeds ~1 KB, summarize the arc and leave the per-run text to git.
7. **Do not promote a one-session pattern to a fortnight's frame (OCT 16).** The OCT 7 run named the long end "the central bank" on one co-fall; name an edge after a single datapoint at `weak`, not `medium`.
8. **Name the marginal narrative before applying a flow edge (OCT 24).** `fed-rate-cut-signaling → flows` and `risk-asset-relative-performance → flows` predict opposite signs on a day like Oct 22 (dovish odds, equity rout). Decide which narrative the tape is trading first; the "rates are the drag" frame has now failed twice in a fortnight (the long end OCT 16; the Fed's next move OCT 24).
